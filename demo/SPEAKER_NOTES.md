# 演示讲稿（3 分钟）· Ising Machine demo

## 开场（30 秒）
"我用一天时间做了个小 demo，把我理解的 Ising machine 跑了一遍。
问题是 MaxCut——NP-hard 的组合优化。40 个点随机连边，把点分成两组，
让跨组边数最多。"

## 图 1：问题与结果（30 秒）
"我没有写搜索算法。而是把每个点写成一个自旋 s_i = ±1，目标变成
最小化 Σ s_i s_j——这就是把优化问题编码成 Ising 能量。然后我造了一个
耦合振子动力学系统去跑这个极小化。结果是 90 条边：和模拟退火打平，
远超贪心（75）和随机（70）。"

## 图 2：分岔（60 秒，核心）
"机器的核心是这个退火过程。看纵轴——连续变量 x（软自旋），横轴是时间。
a 小的时候，势能项把 x 压在 0 附近：系统是软的、在探索（这就是无隙相）。
随着 a 增大，x=0 失稳，发生分岔，自旋一个个长出来、硬化成 ±1（二值相）。
这三个直方图就是同一个过程：单峰 → 展开 → 双峰。最后 sign(x) 就是解。
tanh 饱和这一步，相当于 digCIM 里的数字化操作。"

## 图 3：收敛（20 秒）
"这张是解的割边数随退火参数 a 的变化：机器一路爬到和模拟退火相同的
水平。金色带是我算出来的理论分岔点，和解的质量爬升吻合。"

## 图 4：调参（40 秒，接教授论文）
"最后我想展示'调参决定成败'。换到更难的自旋玻璃实例（SK 模型），
扫描耦合强度 c0：太弱——分岔根本完不成，读出来的是噪声（117）；
中间——140，和调好的模拟退火打平；太强——锁进坏构型（129）。
这和您相分析论文里的图景是同一件事：存在一个'共存区'，动力学参数
要调进去才出好解；怎么规划退火路径走到那里，正是我想深入做的问题——
而且我认为这可以当成一个控制/RL 调度问题来做。"

## 与王教授论文的对应（备用谈资）
- 软自旋 → 无隙相（gapless）；sign(x)/tanh 饱和 → 二值相（binary）
- 分岔点 a* = a0 + c0·μ_min —— 耦合强度和最小本征值决定相边界
- c0 扫描的 U 型 → 相图里"共存区出好解"的同一类现象
- a(t) 的调度 → annealing path planning（arXiv:2603.13778）
- tanh 数字化 → digCIM 的 digitization 操作（arXiv:2507.08533）

## 论文复现实验（digcim_compare.py，见面可现场展示）

复现 arXiv:2507.08533 的 Fig. 4 核心结论：四种机器在 SK 模型(n=400)上
扫增益 a，解码能量对比（温度退火 0.3→1e-5，10k 步）：

| a | CIM | clipCIM | simCIM | digCIM |
|---|---|---|---|---|
| −3.0（顺磁区）| −0.21 | −0.21 | −0.21 | **−0.75** |
| −1.8（分岔后）| −0.65 | −0.65 | −0.68 | **−0.75** |
| −0.6（共存区）| −0.74 | −0.74 | −0.75 | −0.74 |

（基态 = −0.763；SA 基线 = −0.752）

三个要点：
1. CIM 在 a<−2 顺磁（什么都干不了），digCIM 在顺磁区就已找到 TAP 解
   （≈基态）——对应论文"最优解码区覆盖整个 a<0"；
2. CIM 分岔后解码能量 −0.65 ≈ 论文的 −2/π ≈ −0.64，且永远到不了基态；
3. 全部机器的差异只在一行代码：J@x → J@sgn(x)。

实现中踩过的两个坑（诚实可讲）：
- SK 耦合矩阵对称化时方差减半 → 特征值 ±1.4 而非 ±2，修复后对上了；
- 论文操作 digCIM 是"温度退火"（唯一参数），固定微温会冻结在坏构型。

诚实说明：a>0 区段我的模拟因限幅冻结略低于论文理论值；核心结论
（digCIM 在 a<0 全域逼近基态、远胜其他机器）完整复现。
